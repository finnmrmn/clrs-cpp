# clrs-c
Pseudocode implementations and test code in C of algorithms from 
*Introduction to Algorithms* (CLRS), accompanied by Markdown solutions to 
exercises and problems.

## Requirements
- A compiler that supports C23.

## Acknowledgements
Generative AI was used for learning purposes, like generating feedback, Markdown 
formatting, etc. An acknoledgement and justification of usage is provided for 
every task that directly used generative AI to assist the completion. The
justification is to show how the direct AI-generated usage in each case does 
not negatively impact the learning process. 'Direct usage' refers to copying
answers from AI-generated output. 'Indirect usage' refers to reading 
AI-generated output to assist refining and improving answers.
