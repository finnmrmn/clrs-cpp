# clrs-c
Pseudocode implementations and test code in C of algorithms from 
*Introduction to Algorithms* (CLRS), accompanied by Markdown solutions to 
exercises and problems.

## Requirements
- A C++ compiler.

## Acknowledgements
Generative AI was used for learning purposes, like generating feedback, Markdown 
formatting, etc. This is used to refine and improve answers.

An acknoledgement and justification of usage is provided for every task that 
directly copies generative AI output to assist the completion. This is used to 
avoid wasting time on things that have little learning impact. See the chapter 1
problem for an example of this.
